# Tech Challenge - Recipe App

## Descriere
Aceasta este o aplicație React Native pentru gestionarea și vizualizarea rețetelor. Utilizatorii se pot înregistra, autentifica, vizualiza rețete, le pot marca ca favorite, le pot da like sau dislike și pot căuta rețete folosind un prompt AI. Aplicația respectă designul Figma: [link Figma](https://www.figma.com/design/wuHnFuYeOER9m6VOHGmkif/FS-RN-Tech-Challenge?node-id=0-1&p=f).

## Tehnologii folosite
- **React Native**  
- **TypeScript**  
- **React Navigation**  
- **Expo**  
- **AsyncStorage** pentru stocare locală  
- **Figma** pentru design UI  
- **Ionicons** pentru iconițe  

## Structura proiectului
- `RecipeFinder/` – codul frontend React Native  
- `server/` – server local pentru API (opțional, dacă folosești backend)  
- `assets/` – imagini și resurse utilizate în aplicație
